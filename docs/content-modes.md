# 四種內容模式與補查結果驗收

## 顯示規則

一般向排除已確認 BL 和 R18；一般向＋BL 只排除 R18；一般向＋R18 只排除 BL；全部內容不做這兩項排除。兩項標籤同時存在時需選全部內容。unknown、保護級、輔導級不是一般向的排除條件。這是瀏覽偏好，不是年齡驗證或零漏網承諾。

帳號偏好存於 `user_preferences.content_mode`；保留 `general_audience` 供舊客戶端相容。可空新欄位以舊布林值回推，沒有偏好的一般帳號為 general、管理員為 all，不重設已保存設定。舊版寫入布林值仍受理，新版無效模式在資料庫存取前拒絕。

查詢透過 request/thread-local scope 統一處理：統計與分頁先篩選再計數，直接詳情、系列種子與推薦也沿用篩選。通知依各收件者模式處理，不沿用當下網頁的 scope。訪客查詢攜帶模式，快取以模式分開；私人紀錄保留在 IndexedDB，隱藏不等於刪除。備份／匯出不受顯示篩選，訪客匯入帳號不覆蓋帳號偏好。

## 驗收

- 五種樣本：非 BL/R18、只有 BL、只有 R18、兩者重疊、unknown。
- 四模式 SQL 實際執行、別名與通知收件者篩選、跨執行緒／巢狀請求隔離。
- 舊布林值及管理者偏好相容、無效模式拒絕、訪客搜尋／系列篩選。
- 四模式快取隔離、訪客備份保存／舊備份相容與私人紀錄保留。
- 模擬資料的桌面／手機介面：四模式切換與保存、重新整理、多出版社與分頁。
