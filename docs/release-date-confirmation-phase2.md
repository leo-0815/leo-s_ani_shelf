# 日期確認介面（第二階段）

- 商品卡片與詳情區分預定、待確認，以及商品頁日期已確認。已過日期但沒有上市日當天或之後的商品頁日期確認，不再只因日期經過就宣稱已上市。
- 明確標示日期來源與最後成功確認時間（UTC 儲存、台北顯示）；確認的是出版日期，不保證庫存、上架或出貨。月份預估在月底之前不算逾期，延期與取消優先保留。
- 原始 release_status、同步 v1 雜湊與通知條件不變；統計及篩選仍使用原始日期推算分類，介面注明「已到上市日」。不新增資料欄位、爬取額度或執行套件。
- 舊歷史書沒有確認記錄也會顯示待確認；不為了消除標示重爬全書庫。五家每日各 20 本的有限額回查逐步更新近期／預定商品。
- 管理者資料品質頁提供今日各家嘗試／確認／缺日期／失敗／未完成數，最近嘗試與確認時間。一般帳號無權存取 /api/release-checks；本機單人版可用。僅回傳彙總，不傳私人資訊或原始錯誤。
- 每本書每日最多嘗試一次；摘要不是 HTTP 請求數、工作新增數或日期修改數。停止／崩潰且未寫入結果顯示未完成，下一日可重試。摘要時間均按台北日期計算。
- 回查摘要為點開資料品質時的唯讀查詢，沒有背景輪詢、暖機或額外爬取。
