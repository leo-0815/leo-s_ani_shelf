# PR42：訪客模式

## 使用方式

1. 登入頁選「不用註冊，以訪客身分使用」，進入同一個導航首頁。
2. 查書、加入訂選、標記購入、新增自建藏書、追蹤新書或全系列。取消愛心只移除訂選；藏書與系列追蹤是獨立記錄。
3. 在偏好設定下載訪客 JSON 備份；同一頁可還原。還原需確認，只新增缺少的項目，保留現有筆記與偏好。
4. 若要跨裝置同步或 Email 通知，使用 Google 登入。登入後先提供邀請，只有按「查看匯入摘要」才會傳送訪客資料；再確認才儲存到帳號。

帳號已存在的訂選、藏書或追蹤不覆蓋。自建書按書名、作者、出版社、ISBN、版本和漫畫／小說類型去重。公共書目不存在的項目略過並列入摘要，原本資料仍留在瀏覽器。匯入一次最多 1,000 筆；超限不會部分匯入。請求內容上限 1,000,000 bytes，確認 token 10 分鐘有效；過期須重新預覽。

## 儲存與隱私邊界

- 私人資料只存目前網域的 IndexedDB；不建立匿名 users 記錄，不使用共用 user 0。
- 訪客 Cookie 只有 HMAC 簽章識別，HttpOnly、SameSite=Lax，雲端再加 Secure；24 小時到期。服務重啟後可重新簽發，不刪瀏覽器書架。
- 每次查詢／追蹤刷新只傳書目識別碼、系列識別與瀏覽偏好，不传私人筆記、訂單或購入資訊。
- 公共回應有欄位白名單，不能取帳號私人資料。私人雲端 API 繼續要求 Google session 和 CSRF；匯入的目標 user_id 只取自已驗證 session。
- 匯入預覽不寫入，確認後使用單一交易；失敗回滾。原始 IndexedDB 不刪除，重新匯入採 add-only，保留既有內容。
- 不把 Google 帳號的書架下載成訪客資料，兩者是不同的儲存位置。
- 訪客不是不同人的帳號隔離：同一瀏覽器／網域共用同一份訪客書架，使用共用電腦請注意。
- 清除網站資料、無痕視窗關閉、更換瀏覽器／裝置可能遺失。備份包含私人資料，應自行妥善保管。瀏覽器儲存空間不足時明確顯示失敗，不假装儲存成功。

## 功能限制

訪客無雲端 Email／Discord 發送權限及管理員權限。推薦採最多三本已持有公共書目的同系列／作者推薦，不等同登入帳號的完整個人化推薦。公共資料仍需網路；未承諾離線資料及跨裝置同步。一般向只排除已確認 BL／R18，仍不是全年齡保證。

公共查詢依簽章識別各類最多 20 次／60 秒；新識別簽發以實際 socket 來源計算，不信任任意 X-Forwarded-For。Render 代理下新訪客可能共用簽發額度，但有效識別的查詢配額獨立。OAuth 起始仍依實際來源計算，不能用轮換訪客 Cookie 規避。這是單程序保護，不承諾阻止分散式爬蟲或 DDoS。

大型書架／追蹤補齊有分頁與批次限制，碰到限流可稍後重試；已儲存資料保留，不自動密集重試。未新增暖機、第三方儲存服務、AI 模型或資料庫 schema。

## 驗收與開發

- `python -m unittest tests.test_guest -v`：Cookie 簽章／到期、限流、Origin、私人路由拒絕、公共欄位、帳號／CSRF、原始保留、去重與交易回滾。
- `node scripts/test_guest_store.cjs`：交易儲存、取消愛心保留藏書、追蹤、不覆蓋還原、私人資料不上傳、儲存失敗及重整。
- `node scripts/test_guest_ui.cjs`：邀請不傳資料、預覽／確認分開、帳號變更阻止匯入。
- `python -m unittest discover -v` 及 CI 的既有 JavaScript 回歸。
- `python scripts/preview_guest_ui.py`：只綁 `127.0.0.1:8872` 的固定假書目，禁止 DB 連線／雲端寫入。可驗收訪客介面、真實 IndexedDB、保存／重整、自建藏書、備份和還原；不是一般啟動程式或正式部署入口。

本機原版與雲端工作樹保持分開。此 PR 不更動本機 MySQL、青文補查或每日 Actions 爬蟲。
