# 搜尋導覽（PR49）

## 介面

- 側欄、頁面標題與瀏覽器標題由 Library 改成「書目查詢」。`#library` 路由和 API 不變，既有連結與書架資料不受影響。
- 首頁與其他搜尋欄均顯示 Ctrl／⌘ K 提示，輔助技術另有 `aria-keyshortcuts`。手機隱藏鍵盤按鍵徽章，不影響搜尋。
- 書目查詢頁使用精簡 sticky 搜尋列，包含原本的搜尋欄、出版社多選及「篩選條件」按鈕；日期、類型、內容分類等詳細條件不整組固定。
- 「篩選條件」回到詳細列並聚焦類型選單，依固定列實際高度保留空間，避免被遮住；尊重減少動態效果設定。
- 高度不超過 450px 的視窗（例如手機橫向）不固定搜尋列，避免占掉閱讀空間。出版社選單可捲動且限制高度。

## 行為與範圍

搜尋列移動的是同一個 DOM 節點，不建立第二套輸入值或事件。切換回訂選、藏書、系列頁時，搜尋欄回到原本頂部位置。書目查詢固定列不影響私人書架或偏好。

Ctrl＋K／⌘＋K 在首頁聚焦首頁搜尋；搜尋頁聚焦現有欄位；其他已登入頁切換書目查詢再聚焦。搜尋欄已可見時不改變捲動位置；不可見時捲至可操作位置。登入尚未完成、IME 組字中、Alt 修飾鍵或 modal 開啟時不攔截，避免打斷操作。

沒有新增網路／資料庫請求、捲動輪詢或後端變更。搜尋維持原本 debounce、偏好交集、限流與快取；此 PR 不修改分級、私人資料、爬蟲或部署設定。

## 驗收

- 單一搜尋欄、搜尋字串保留、中文標題及既有路由。
- Ctrl／⌘ 快捷鍵、非搜尋頁切換、modal／登入／IME 保護。
- 回到篩選條件的焦點與減少動畫設定。
- 本機合成書目：桌面往下捲動後列仍在頂部，Ctrl＋K 不跳頁；390×844 手機無橫向溢出，選單在視窗內可操作；844×390 短視窗使用非固定列。
