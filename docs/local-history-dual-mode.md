# 本機歷史書目雙模式

執行 `歷史資料更新.bat`。視窗打開不會連資料庫、抓書或同步，直到手動選擇模式。

- **系列定向補查**：列出已有系列和數字卷號缺口（至多 30 筆，可用系列名縮小範圍）。卷號缺口只是候選，不代表官方有出版。盤點不套用個人內容偏好。角川可填官方系列分類 URL（義妹生活有預設入口）；尖端可填官方分類或單本商品連結。每次最多三頁角川清單、25 個商品頁。只有同系列、同媒體、有效 ISBN 才列為候選。套書不拆分。確認新增前不寫入，不改藏書、訂選或歷史斷點。
- **地毯式回填**：仍使用既有出版社／年度／分類斷點。有 30 分鐘、1 小時、跑完當前年份或持續執行四種選項。沿用原本的雲端同步，未完成的批次不推進。

角川多規格商品只在官方規格明確同時列出單一數字卷號及有效 ISBN 時納入。沿用 ISBN 當商品識別，不把母商品的上市日期、封面、價格或分級套給各卷。沒有逐卷證據時保持未確認。尖端舊商品也接受由其單本頁公開提供、通過檢查碼的台灣商品條碼。

新增到本機後，可第二次確認只上傳本輪新增書目。先用既有公共書目快照比對雲端商品 ID 與 ISBN，不送已存在的項目。此檢查不是伺服器的原子鎖；如果雲端剛好同時更新同一商品，仍由既有同步合併規則處理。不會送私人資料、不推進一般同步游標、不順帶上傳其他待同步書目。

## 登入後五分鐘顯示選單

在專案目錄執行 `powershell -File scripts/install_history_logon_task.ps1`。這會為目前 Windows 使用者建立 `AniShelf History Menu` 工作；使用登入而非開機事件，確保能在桌面看見視窗。它只開選單，沒有自動選項。裝好不會補跑本次登入，從下次登入生效。可在工作排程器停用，或以 `Disable-ScheduledTask -TaskName 'AniShelf History Menu'` 停用。移動專案目錄後須重新安裝排程。
