# 青文：本機 HTML 匯入

青文暫不進入 GitHub Actions 的每日抓取、近期防漏補查和每日分級更新。東販、角川、東立、尖端的排程不變；既有青文書目和使用者資料不會因此刪除。

將已存好的青文漫畫／小說列表或單本商品頁 HTML 放入本機專案的 `inputs/chingwin/YYYY/MM/DD/`。可直接放當日目錄，也可以放其下的 `list/`、`detail/`。例如 `inputs/chingwin/2026/11/28/`。此根目錄已列入 Git 忽略清單，不要將原始頁面或本機設定提交。

- 在既有本機專案雙擊「書目更新.bat」，選 **4. 手動匯入青文 HTML**；沒有歷史回填選單的檢出版本會直接進入青文匯入器。
- 預設讀台北時間當天。要補匯以前的某天，可在 PowerShell 執行 `.\書目更新.bat --date 2026-11-28`；也可用 `python -m app.chingwin_local_import --date 2026-11-28`。
- 程式只讀指定日期，並在該日資料夾建立 `pending_chingwin_urls.txt`，列出本機未收錄或分級未知、而且沒有同批商品頁的項目。它不會替使用者下載網址。
- 確認匯入後在本機 MySQL 更新書目，成功的 HTML 會搬到 `inputs/chingwin/done/YYYY-MM-DD/`。若是已有同步用戶端的本機版本，雲端同步會另外詢問，不會在未確認時啟動。只含雲端伺服器程式的 Git 分支沒有這個同步用戶端，使用該分支的批次檔只寫入本機。

本機歷史回填的青文也只讀上述日期目錄，依日期由舊到新處理，不連青文官網。成功寫入才歸檔；解析不成功的 HTML 和寫入失敗的批次保留原處。其他出版社仍用既有線上回填及斷點。Notebook 或其他程式若要唯讀核對本機檔案，可以呼叫同一模組的 `read_saved_history()`，不會寫入或移動檔案。

若現有本機版本與部署分支不同，只安裝 `app/chingwin_local_import.py` 與「書目更新.bat」，不要用部署分支整批覆蓋本機的回填、資料庫設定或同步程式。
