# 東販公開資料備援（PR55）

- 僅讀取公開頁面，不使用會員 Cookie、不登入、不處理年齡驗證。
- 小型會員跳轉頁明確回報「來源需登入」，不再誤報缺少標題；分級補查也視為抓取失敗，不是假裝已確認未知。
- 公開商品卡片只取相同 ID 的書名、官方封面與網址。不把優惠價當定價，不猜日期、ISBN、作者、BL、R18 或漫畫／小說類型。
- 純清單種子類型為 unknown，既有書目不被稀疏資料覆蓋；後續完整商品頁用同一 source ID 更新原筆。預設漫畫／小說搜尋不會把未確認類型當漫畫展示。
- 日常商品擷取、日期與分級候選共用東販的持久化補查退避。登入受限商品在補查失敗後間隔七天再試；一般網路失敗沿用指數退避。
- 待補佇列不會因保存清單種子而標記成功；來源限制仍可能造成部分更新警告。全面監控訊息與東立卡住商品留給 PR57。
- 不變更 schema、分級解析版本、使用者偏好或私人書架。
