# PR54：窄螢幕頁面選單

900px 以下以左上角三條線開啟中文側邊抽屜，取代原本底部純圖示列。使用同一份桌面導覽 DOM，不複製路由或角色控制；管理員專用項目沿用既有權限，開關選單不發 API。

原生 modal dialog 提供焦點限制、Esc 關閉與背景互動隔離。可按 ×、點背景或選頁關閉；關閉後恢復頁面捲動。切回桌面自動關閉並將原側欄移回。保留既有快取、搜尋／篩選／分頁狀態、快捷鍵和帳號設定；登入過期時先關閉抽屜，避免擋住登入頁。

- 320px／390px：完整中文頁名可見，無水平溢出。
- 按 Esc 後焦點回到三條線；aria-expanded、背景捲動同步恢復。
- 點選書目頁後抽屜關閉，當前頁有 aria-current 標記。
- 點背景、× 及窄／寬螢幕切換正常；桌面側欄只有一份。
- 唯讀 fixture 的一般帳號看不到資料品質與資料來源兩個管理項目。
- 首次逐頁載入後再切 9 頁：API 12 → 12，沒有錯誤提示。這是本機 UI 驗收，不冒充已部署正式站。
- Node 模組測試涵蓋開關、焦點入口、原生 dialog、捲動鎖、背景點擊、選項點擊及 resize；選單模組不使用 fetch/API。
