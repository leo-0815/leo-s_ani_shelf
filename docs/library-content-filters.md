# Library 內容分類篩選（PR48）

分類與偏好分開：偏好決定「可以顯示什麼」，篩選決定「這次想找什麼」。

| 篩選 | 條件 |
| --- | --- |
| 所有可見內容 | 只沿用偏好，不額外限制 |
| 一般向（非 BL／R18） | 沒有正向 BL 標記，而且不是限制級；未知仍可見 |
| BL | 有 `bl_category` 官方標記，可包含同時是 R18 的書 |
| R18 | `content_rating = restricted_18`，可包含同時是 BL 的書 |
| BL 且 R18 | 同時有 BL 與 R18 標記，不是兩類的聯集 |

「一般向＋BL」偏好下的 BL 篩選仍排除 R18；「一般向＋R18」下的 R18 篩選仍排除 BL；只有全部內容可查「BL 且 R18」。無法使用的選項會停用並標示「偏好未開啟」，改偏好後自動清除已不允許的選擇。不改任何現有帳號偏好。

API：`GET /api/books?content_filter=bl`，訪客為 `/api/guest/books`。合法值為空字串、`general`、`bl`、`r18`、`bl_r18`；無效值回應 400。條件在 SQL 計數與分頁前套用，與原本可見性及出版社等條件取交集；不能靠修改 URL 繞過帳號偏好。原有查詢限流、成本保護與快取繼續適用，沒有新增查詢、模型或爬蟲，也沒有修改資料表。

UI 僅 Library 顯示此篩選；切換私人訂選或藏書不會暗中沿用 Library 的分類篩選。訪客若透過程式呼叫私人瀏覽器書架，仍以相同正向標記規則在計數／分頁前篩選，不刪除儲存的資料。

目前沒有獨立的逐本男性向／女性向欄位，因此不提供會誤導的空選項，也不把 BL 當女性向、非 BL 當男性向。日後需加入官方逐本分類來源及可追溯證據；未知保持未知。青文出書表的 BOY／GIRL 標籤可作來源之一，但不能將出版社或書系的推測擴大套用到每本書。

測試涵蓋四種偏好 × 五種篩選，登入與訪客 SQL、BL/R18 重疊、未知與輔導級、交叉條件、計數／分頁、無效參數與前端清除／停用選項。
