# 青文分級與保守篩選

## PR29：官方規格解析

只讀取 HTTPS 青文商品頁、商品編號相符的自身規格區塊。官方「普／普遍級」對應 general，「18限／限／限制級」對應 restricted_18；其他標籤、欄位缺失、SKU 不符、衝突一律 unknown。推薦區與相關文章的分級不能套到目前商品。新爬蟲資料會補查分級；未知結果不會抹掉既有已確認結果，人工鎖定保持優先。

## PR30：舊資料補查

無新增第三方套件、無模型或圖片下載。只補青文未知分級，不重新建立書目、不修改藏書與帳號資料。獨立 book_rating_checks 逐本保存 checkpoint；失敗隔天可重試，缺標籤七天後可重試。完成時間只決定何時停止，單一 HTTP 請求最長 20 秒、最多兩次，請求間隔 1.5 秒，不測試網站壓力上限。

本機主版本雙擊「分級資料補查.bat」，可選 30 分鐘、1 小時、目前未知資料完成、持續執行或只測 10 筆。這個入口不會改動既有「歷史資料更新.bat」。Ctrl+C 前已完成的書籍與 checkpoint 會保存；尚未完成的一本下次重試。正常離開或 Ctrl+C 後嘗試同步；如果 POST 失敗，持久待上傳紀錄不標記成功，下次執行重試。停止同步本身時也保留未確認項目。

雲端版本可使用以下命令直接補 TiDB；--sync 只適用於含 CatalogSyncClient 的本機版本：

```powershell
python anishelf.py ratings --dry-run --limit 10
python anishelf.py ratings --mode 30m
python anishelf.py ratings --mode 60m
python anishelf.py ratings --mode complete
```

本機同步範例：`python anishelf.py ratings --mode 30m --sync`。dry-run 不建表、不寫入資料、不上傳。同步只傳書目分級等公共欄位，不傳個人收藏、備註或通知設定。需先完成既有 catalog-sync token 設定。

## PR31：逐本放行（部署後生效）

一般向只放行青文 content_rating=general、來源 publisher／manual、confidence=100 的書。未知、缺失、衝突、12／15 等未支援標籤仍隱藏；已知 restricted_18 在所有出版社都隱藏。條件於後端分頁前套用，含搜尋、書籍／系列詳情、推薦、近期上市、藏書與統計。出版社清單依可見書目計數，不再整家封鎖。管理員與使用者既有偏好不重設。

這不是整站內容安全保證：其他出版社的未知分級仍依既有政策顯示，私人手動書籍沒有官方分級。青文普遍級可能仍有戀愛、戰鬥或非露骨的成熟題材；不把 BL／GL 類型直接等同成人。若官方標普但封面／簡介疑似成人，應人工設為 unknown 或 restricted_18 並鎖定，寧可暫不放行。
